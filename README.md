# EXP-7
# Groq LLM Prompting Experiment: Romeo and Juliet

## Aim
To explore how different prompt instructions influence the responses generated by a large language model.

## Objective
Generate summaries of *Romeo and Juliet* using three different prompts and compare their outputs.

## Technologies Used
- Python
- Groq API
- OpenAI Python SDK
- Google Colab

## Model
`llama-3.3-70b-versatile`

## Prompting Methods
1. **Baseline:** Summarize *Romeo and Juliet* in one paragraph.
2. **Constraint-based:** Summarize the story in exactly two sentences using simple English.
3. **Role-based:** Act as a romantic writer and describe Romeo and Juliet's forbidden love in two simple-English sentences.

## Methodology
1. Connect to the Groq API using a securely stored API key.
2. Define the three hardcoded prompts.
3. Send each prompt to the model.
4. Display the generated responses.
5. Compare how prompt instructions influence the output.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Add `GROQ_API_KEY` to Google Colab Secrets.
3. Run `experiment.py` in Google Colab or adapt the secret-loading code for your local environment.

## Safety
Never commit API keys, passwords, or other credentials to the repository.
